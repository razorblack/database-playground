# Database Playground 🗄️

A hands-on playground for learning, experimenting with, and showcasing database design concepts using real-world examples.

## What's Inside

| Project | Description |
|---------|-------------|
| [BookMyShow DB Design](./bookmyshow-db-design/) | Database schema design for a movie ticket booking platform - covers normalization, entity relationships, and practical SQL queries |

## Purpose

This repo serves as my personal lab for:
- Practicing database schema design from scratch
- Understanding normalization forms (1NF through BCNF)
- Writing efficient SQL queries
- Documenting the thought process behind design decisions

## How to Use

Each folder contains a self-contained project with:
- `README.md` - Problem statement, approach, and detailed explanation
- `schema.sql` - Executable SQL that you can run directly on MySQL

Feel free to clone and experiment!
